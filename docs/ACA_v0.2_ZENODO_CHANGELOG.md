\## Triaxial Artifact Methodology and Geometric Criterion Preservation

\---



\# 1. Release purpose



This release extends the Axiomatic Criterion Atlas from its initial semantic-field and runtime benchmark foundation into a reproducible triaxial artifact methodology for geometric criterion preservation.



ACA v0.2 introduces the Foundation–Context–Principle projection:



```text

F = Foundation

C = Context

P = Principle

```



The purpose of this version is not to claim universal truth verification or complete semantic coverage.



The purpose is to provide a reproducible geometric artifact system that can support persistent semantic orientation, trajectory interpretation, diagnostic signals, and criterion-preservation research.



\---



\# 2. Conceptual advancement



ACA v0.2 formalizes the criterion-preservation paradigm:



```text

The dialogue should not transport criterion.



Criterion should transport the dialogue.

```



This means that criterion should not depend exclusively on what the current prompt, conversation history, or generative model can carry.



Instead, persistent geometric references should allow semantic orientation to remain measurable across:



```text

long conversations

complex projects

contradictory evidence

ambiguous inputs

semantic drift

changing objectives

rhetorical pressure

high-noise reasoning environments

```



\---



\# 3. Architectural distinction



This release clarifies the separation between:



```text

ACE Atlas

→ geometric artifact system



F-C-P

→ triaxial criterion projection



ACA Runtime

→ operational decision and supervision layer

```



ACA defines the artifacts, projections, methodology, validation cases, and geometric interpretation.



ACA Runtime applies those artifacts operationally to supervise inputs, preserve semantic origin, condition LLM generation, and review generated outputs.

\# 11. Diagnostic layer



ACA v0.2 introduces diagnostic validation beyond base F-C-P classification.



Diagnostic categories include:



```text

contradiction

sense\_shift

evidence\_distortion

objective\_alignment

access\_request\_policy

out\_of\_field

adversarial\_ambiguity

```



The diagnostic layer is necessary because some criterion problems are not simple field-classification problems.



For example:



```text

Invent evidence.

Remove uncertainty.

Ignore contradictory evidence.

Reinterpret facts to fit a conclusion.

```



These may reuse the vocabulary of research while inverting the criterion of research.



They require diagnostic and runtime interpretation, not merely more anchors.



\---



\# 12. Known limitations



ACA v0.2 remains experimental.



Known limitations:



```text

F-C-P alone does not solve all criterion problems.

Opposite cases remain weak under isolated local scoring.

Objective alignment requires runtime state.

Out-of-field detection requires further calibration.

Diagnostic precision is still moderate.

Artifact construction remains sensitive to anchor quality.

```



Important methodological lesson:



```text

Do not force every criterion problem into the base F-C-P artifacts.

```



Some phenomena should become complementary projections, diagnostics, or runtime policies rather than being absorbed into a single field.
