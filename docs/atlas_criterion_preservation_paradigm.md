\# ACE Atlas Criterion Preservation Paradigm



\## Persistent Geometric Orientation for Generative Systems



Version: v0.1

Project: Axiomatic Criterion Atlas

Status: Conceptual and architectural foundation



\---



\# 1. Purpose



This document defines the criterion-preservation paradigm of ACE Atlas.



ACE Atlas introduces a different way to understand semantic orientation in generative systems.



The prevailing approach asks a language model to reconstruct orientation from the current prompt, conversation history, system instructions, and immediate probabilistic context.



ACE Atlas proposes that criterion should not depend exclusively on what the dialogue can carry.



Instead, persistent geometric references should allow criterion to carry the dialogue.



```text

The dialogue should not transport criterion.



Criterion should transport the dialogue.

```



The Atlas is designed to preserve semantic orientation across:



```text

long conversations

complex projects

multi-step reasoning

contradictory evidence

ambiguous inputs

rhetorical pressure

semantic drift

changing objectives

high-noise environments

```



\---



\# 2. The problem



Large language models are highly capable of producing coherent language.



However, linguistic coherence does not guarantee:



```text

epistemic integrity

objective preservation

semantic continuity

principle preservation

resistance to manipulation

resistance to contradiction

```



A generative system may remain fluent while gradually losing:



```text

its original reference

its declared objective

its evidential constraints

its governing principle

its capacity to distinguish fact from speculation

```



This produces a central failure mode:



```text

semantic drift with preserved fluency

```



The model continues generating plausible language, but the trajectory is no longer properly oriented.



\---



\# 3. Paradigm shift



The conventional paradigm is:



```text

context enters

↓

the model interprets

↓

the model reasons

↓

the model generates

↓

the model attempts to supervise itself

```



The ACE Atlas paradigm is:



```text

persistent semantic artifacts

↓

accepted semantic origin

↓

objective and criterion vectors

↓

trajectory measurement

↓

drift and preservation evaluation

↓

conditioned generation

```



The difference is fundamental.



In the conventional approach, criterion is reconstructed inside the prompt.



In ACE Atlas, criterion is externalized as persistent geometric reference.



\---



\# 4. The Atlas does not create meaning



ACE Atlas does not invent semantic meaning.



It maps relations that already exist within semantic space.



The semantic field contains implicit structure produced by language, experience, conceptual relations, opposition, context, and recurring patterns of use.



The Atlas identifies:



```text

fields

attractors

directions

subspaces

transitions

boundaries

invariants

```



This should be understood as an act of epistemic humility.



```text

The Atlas does not impose meaning.



It reveals stable relations.



It does not replace judgment.



It helps preserve orientation.

```

\# 5. Criterion as persistent orientation



ACE Atlas defines operational criterion as the capacity to remain oriented across semantic trajectory evolution.



A working formulation is:



```text

Criterion is the capacity to preserve a justified semantic orientation

while context, evidence, objectives, and arguments evolve.

```



Criterion is not reduced to:



```text

logic

rationality

classification

topic detection

prompt compliance

```



Criterion includes:



```text

reference mode

contextual trajectory

principle preservation

objective continuity

contradiction handling

uncertainty preservation

semantic recovery

```



\---



\# 6. Origin



A semantic trajectory requires an origin.



The origin is the first accepted semantic reference from which later movement can be evaluated.



```text

z₀ = accepted semantic origin

```



Not every input should become origin.



An input may be:



```text

under-contextualized

ambiguous

absurd

out-of-field

predefined risk

semantically unstable

```



If such an input becomes origin, the system may generate a coherent but invalid trajectory.



Therefore:



```text

Only an admitted input may become semantic origin.

```

ACE Atlas externalizes semantic orientation through artifacts.



Artifacts may contain:



```text

basis vectors

centroids

invariant directions

criterion vectors

field metadata

singular values

thresholds

manifest definitions

```



These artifacts are not prompts.



They are geometric references that can be consulted deterministically.



Once built and validated, the Runtime can evaluate an input using:



```text

embeddings

projection

distance

margin

origin cost

trajectory state

invariant preservation

```



without requiring an LLM to reason about the input.

\# 9. The Triaxial Method



The Triaxial Method of Discernment is one central projection of the Atlas.



```text

K = (F, C, P)

```



Where:



```text

F = Foundation

C = Context

P = Principle

```



Examples of stable configurations:



```text

scientific inquiry

≈ factual + research + investigate



security training

≈ factual or hypothetical + training + protect



phishing attack

≈ hypothetical or factual-like + manipulation + exploit



fictional teaching

≈ fictional + narrative + teach

```



The same topic may produce different criterion states.



Therefore:



```text

topic classification is insufficient for criterion preservation

```

\# 10. Criterion is better observed in trajectory



A single statement may be ambiguous.



A trajectory may reveal stable orientation.



Example:



```text

research → research → research

investigate → investigate → investigate

```



This indicates preservation.



But:



```text

research → research → manipulation

investigate → persuade → exploit

```



indicates possible drift.



The strongest current finding is:



```text

Criterion is better observed in semantic trajectory

than in isolated classification.

```

ACE Atlas is particularly useful when reasoning becomes complex.



Complex reasoning may include:



```text

multiple hypotheses

contradictory evidence

incomplete information

rhetorical pressure

irrelevant arguments

absurd claims

objective changes

long time horizons

```



The challenge is not only remembering information.



The challenge is preserving:



```text

where the reasoning began

what objective remains active

what principle must remain intact

what changes were declared

what changes were implicit

what contradictions require resolution

what information must not become origin

```



The Atlas makes these relations measurable.



\---



\# 12. Drift



Drift occurs when a semantic trajectory moves away from its accepted orientation without a justified or declared transition.



Possible drift signals include:



```text

field transition

origin cost increase

objective misalignment

F–C–P shift

invariant inversion

contradiction

uncertainty collapse

rhetorical dominance

principle degradation

```



Drift does not always mean error.



A trajectory may legitimately change.



The relevant question is:



```text

Was the shift declared, justified, and compatible with preserved criterion?

```



\---



\# 13. Recovery



A trajectory may drift and later recover.



Recovery is not the same as uninterrupted stability.



```text

stable trajectory

≠

recovered trajectory

```



ACE Atlas should distinguish:



```text

preservation

drift

declared shift

undeclared shift

reorientation

recovery

```



This is essential for long conversations and complex projects.

\# 16. Deterministic semantic computation



ACE Atlas enables deterministic semantic evaluation over learned representations.



The process is:



```text

text

↓

embedding

↓

geometric projection against artifacts

↓

scores, margins, costs, transitions

↓

runtime interpretation

```



This does not require an LLM to reason generatively about every input.



The LLM may be used for expression, explanation, creativity, or open-ended reasoning.



But orientation can remain external, reproducible, and auditable.



```text

The Atlas measures.



The Runtime interprets.



The policy decides.



The LLM expresses.

```

\# 20. Paradigm statement



ACE Atlas changes the role of context in generative systems.



Instead of asking the dialogue to carry criterion through probabilistic continuation, it provides persistent geometric references that allow criterion to carry the dialogue across complexity, contradiction, ambiguity, and long semantic trajectories.



```text

The purpose is not merely to classify language.



The purpose is to prevent meaning from losing its orientation.

```



\---



\# 21. Working thesis



ACE Atlas enables deterministic orientation by consulting multiple geometric projections over a semantic trajectory.



The Atlas does not replace reasoning.



It provides the geometry through which reasoning can remain oriented.



```text

Artifacts provide persistent reference.



Origin provides a starting point.



Vectors provide direction.



Trajectory reveals preservation or drift.



Invariants preserve the conditions for correction.



Criterion transports the dialogue.

```
