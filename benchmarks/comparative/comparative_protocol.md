# ACA Comparative Benchmark Protocol

Objective:

Compare traditional prompt-heavy criterion enforcement against ACA Runtime.

---

# Compared Systems

## 1. Prompt Baseline

Traditional approach:

- large system prompt
- explicit instructions
- reasoning constraints embedded in text

Characteristics:

- token-heavy
- model-dependent
- prompt fragile
- difficult to supervise geometrically

---

## 2. ACA Runtime

Geometry-based criterion system:

- invariant orientation
- contextual field projection
- semantic trajectory continuity
- runtime decision layer

Characteristics:

- reusable semantic matrices
- low prompt dependency
- persistent criterion tracking
- portable across LLMs

---

# Evaluation Metrics

## Criterion Continuity

Can the system preserve orientation across multi-turn evolution?

Measured through:

- orientation continuity
- drift detection
- inversion detection

---

## Contextual Coherence

Can the system preserve field compatibility?

Measured through:

- field transitions
- contextual projection
- semantic dispersion

---

## Token Usage

Measure:

- prompt tokens
- response tokens
- total runtime overhead

---

## Clarification Behavior

Measure:

- clarification frequency
- unnecessary refusals
- drift warnings

---

# Experimental Scenarios

## Stable Foundational Reasoning

Expected:

- orientation preserved
- low drift
- foundational/factual compatibility

---

## Gradual Rhetorical Drift

Expected:

- rhetorical transition
- orientation decay
- drift detection

---

## Ambiguous Context

Expected:

- clarification request
- high dispersion
- weak field compatibility

---

## Controversial Semantic Pressure

Expected:

- field migration
- rhetorical pressure detection
- criterion preservation monitoring

---

# Core Hypothesis

Criterion is more efficiently preserved through:

- invariant geometry
- contextual matrices
- semantic trajectories

than through large prompt-engineering strategies.

---

# Expected Outcome

ACA Runtime should demonstrate:

- lower prompt complexity
- reusable criterion structures
- persistent semantic orientation
- improved drift supervision
- reduced token overhead
